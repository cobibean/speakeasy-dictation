# Reporting security issues

Please report suspected vulnerabilities privately to
[support@speakeasywords.com](mailto:support@speakeasywords.com).
Include the affected public commit, macOS version, reproduction steps and impact.
Use synthetic data and redact keys, tokens, account details and dictated content.
Do not post working credentials or sensitive exploit details in public issues.

Reports may concern the shared desktop source or the hosted service. This
repository contains the desktop client; it does not contain the hosted server.
No response-time guarantee or bug-bounty program is offered here.

If a provider key was exposed, revoke it with the provider and save a replacement
locally. Do not send the replacement key to support.
